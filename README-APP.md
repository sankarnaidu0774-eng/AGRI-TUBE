# Agriculture Tube

A responsive, agriculture-focused video discovery app built with plain HTML, CSS, and JavaScript.

## Run locally

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Then open `http://localhost:3000`.

## Features

- Custom sprout/play-button logo (`assets/logo.svg`)
- Responsive desktop, tablet, and mobile layouts
- Agriculture video catalog and category filters
- Instant search (Ctrl/Cmd + K)
- Interactive video preview modal with playback progress
- Likes, subscriptions, sharing, and locally persisted saved videos
- Watch history, following, and curated playlist views
- Notifications, profile menu, field note, and upload flow

This is a front-end demo. Uploaded videos are not sent to a backend, and the video player simulates playback using preview imagery.
